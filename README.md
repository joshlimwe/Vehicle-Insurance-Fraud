1. Problem Description
Insurance fraud is a pervasive and increasingly sophisticated threat to the automobile industry, contributing to significant global losses each year. Fraudulent claims, such as staged accidents, inflated repair costs, or manipulated policy information, distort insurers’ risk calculations and impose financial burdens on honest customers through higher premiums. However, despite its severity, fraud detection remains challenging. Fraud cases are rare and highly diverse, making them difficult to distinguish from legitimate claims. Though claim information is structured, it can contain complex interactions and fraud patterns evolve quickly as fraudsters learn to adapt to existing control. 

Given these challenges, automated and data-driven approaches have become essential. This project aims to develop a machine learning-based fraud detection pipeline that can uncover subtle, non-linear patterns in claim behaviour and assess fraud risk more effectively than traditional rule-based systems. By combining predictive modelling with robust evaluation metrics tailored to imbalanced fraud scenarios, our solution seeks to help insurers identify suspicious claims earlier, reduce financial losses, and improve fairness and trust for genuine policyholders.
2. Data Overview
Source: Vehicle Insurance Fraud Detection Dataset published on Kaggle by Khushee Kapoor.
It contains 15,404 insurance claim records, each labeled to indicate whether the claim was identified as fraudulent (FraudFound: Yes/No). 
This dataset is suitable for supervised learning as the fraud outcome is known.
